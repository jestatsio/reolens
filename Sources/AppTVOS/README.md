# AppTVOS — Apple TV viewer library (0.7.0)

Thin, tvOS-facing library for the Reolens **living-room viewer**. Mirrors
the `AppWatch` precedent: it depends only on `ReolinkAPI` +
`ReolinkStreaming` and **never on `AppShared`**, so the tvOS build stays
small and avoids the ~30 `AppShared` files that touch UIKit / Photos /
HomeKit / ActivityKit (which would force a pile of `#if os(tvOS)` blocks,
against AGENTS.md §2).

## Scope

Live view only — a focusable camera grid that pushes a fullscreen RTSP
live view. No recordings, PTZ, or settings (those stay on iPhone / iPad /
Mac). Notifications are NOT a tvOS concern: tvOS can't hold a background
listener, so the always-on Mac **Hub** drives notifications for every
device.

## How it gets data (no AppShared)

- **Camera list:** `TVCameraListStore` reads the shared `cameras.json`
  from the iCloud Drive ubiquity container — the same file the Mac/iOS
  apps publish via `AppShared.ICloudCameraStorage`. `TVCameraEntry` is a
  **decode-only mirror** of the fields the TV needs.
- **Credentials:** `TVCredentialReader` fetches the encrypted
  `CameraCredential` records the Mac/iOS apps publish to the user's
  private CloudKit DB when "Stream on Apple TV" is enabled. Held **in
  memory only** (tvOS has no durable Keychain; AGENTS.md §4). The password
  rides `CKRecord.encryptedValues` — ciphertext-only on the server.
- **Live video:** `TVLiveFullscreenView` builds RTSP URLs with
  `StreamURLs` and plays them with `ReolinkStreaming.LiveVideoPlayer` —
  no `CameraSession` needed.

## ⚠️ Contracts to keep in sync

These mirror types decode data produced by `AppShared`. A field drift
silently drops data on tvOS:

- `TVCameraEntry.CodingKeys` ↔ `CameraEntry`'s custom encoder in
  `Sources/AppShared/CameraStore.swift`.
- `TVCredentialReader`'s record type / keys ↔ `AppShared.CameraCredential`.

**Follow-up:** factor `CameraEntry` (and the `CameraCredential` record
contract) into `ReolinkAPI` so there's one source of truth instead of a
hand-mirror — see the 0.7.0 roadmap.

## Why it also compiles for macOS

The library uses only cross-platform SwiftUI, so `swift build` (host =
macOS) and CI can type-check it. The actual product is the tvOS app
target (`ReolensTVOS`) in `AppiOS/ReolensiOS.xcodeproj`, generated by
xcodegen from `AppiOS/project.yml`.
